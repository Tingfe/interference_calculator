# Interference Calculator 2.0 维护版用户手册

本手册对应 `maintenance/original` 分支。这个分支保留原作者软件的通用元素 /
同位素组合扫描功能，并使用现代化后的同位素数据库、Python 3、PyQt5 和谱图界面。
GDMS、ICP-MS、SIMS 等无机质谱专项功能在 `main` 分支维护。

## 1. 主界面

![主界面](images/main_zh.png)

主界面分为三块：

- 顶部栏：显示软件名称，并提供语言切换。
- 左侧控制栏：设置目标峰、窗口、元素列表、离子模型和仪器 MRP。
- 右侧结果区：显示结果概览、候选峰表格和空状态提示。

## 2. 语言切换

右上角可以在 `English` 和 `中文` 之间切换。切换后会同步更新主窗口、表格、
状态栏、帮助内容和谱图标题。

## 3. 输入元素

在 `样品元素 / 元素` 中输入参与通用扫描的元素，元素之间用空格分隔。

示例：

```text
Ca O H Si
```

软件会自动使用这些元素的天然同位素组合。元素越多、最大原子数越大，组合数量越多，
计算时间也会明显增加。

## 4. 添加常用元素组合

`添加组合` 会把常用元素集合追加到元素框，不覆盖已有元素。维护版提供：

- 全元素
- 常见轻元素
- CHNOPS
- 卤素 / 硫
- 过渡金属基体
- 硅酸盐基体

全元素适合检查数据库覆盖或做粗筛，但计算量可能非常大，建议配合目标峰和较小的
最大原子数使用。

## 5. 输入目标峰

目标峰可以留空，也可以输入：

- 同位素：`56Fe`
- 分子式：`40Ca16O`
- 数值 m/z：`55.9349`

如果目标峰留空，软件会枚举所选元素在最大原子数内的全部组合，结果可能很长。

## 6. 设置窗口

窗口宽度按完整窗口输入。

例如 `0.3 m/z` 表示搜索目标峰两侧各 `0.15 m/z`。如果输入了有效目标峰，可以切换
到 `ppm`，软件会自动在 `m/z` 和 `ppm` 之间换算当前窗口值。

开放式扫描没有目标峰时，建议使用 `m/z` 单位。

## 7. 离子模型

`离子模型` 包含：

- `离子`：选择 `1+`、`1+, 2+`、`1+, 2+, 3+`、`1-` 或中性。
- `最大原子数`：限制候选组合中允许的最大原子数。
- `仪器 MRP`：用于标记候选峰是否能与目标峰分辨。

MRP 不影响候选峰生成，只影响结果中的可分辨判断和谱图高亮。

## 8. 计算结果

点击 `计算` 后，结果表会显示：

- `离子`
- `类型`
- `电荷`
- `m/z`
- `Δm/z`
- `Δppm`
- `MRP`
- `概率`
- `可分辨`

重点关注 `MRP` 和 `可分辨`：如果当前仪器 MRP 小于分辨该候选峰所需的 MRP，
该峰会标记为不可分辨。

## 9. 谱图

点击谱图按钮可以查看候选峰分布。

![谱图](images/spectrum_zh.png)

有目标峰时，谱图会以目标峰为中心显示；ppm 模式下横轴为 `Δppm`。

## 10. 同位素比

点击 `同位素比` 可以查看当前元素的同位素丰度、相对比值、倒数比值和数据源。
这适合快速确认元素天然同位素组成。

## 11. Python 调用

```python
import interference_calculator as ic

data = ic.interference(
    ['Ca', 'O', 'H', 'Si'],
    'Fe',
    targetrange=0.3,
    maxsize=4,
    charge=[1],
    chargesign='+',
)

ratios = ic.standard_ratio(['Ca', 'O'])
```

API 中的 `targetrange` 是 m/z 半窗口。GUI 中输入的是完整窗口宽度，软件会自动换算。

## 12. 分支说明

- `maintenance/original`：现代化维护后的通用扫描分支。
- `main`：无机材料 / GDMS、ICP-MS、SIMS 专用主分支。
